🔹 Project Overview
      - Manage different types of mission requests (Normal, Emergency, Abort)
      - Simulate mission lifecycle:
            _Request submission
            _Rover assignment
            _Execution and completion
      - Track rover states:
            _Available
            _In execution
            _Under maintenance
      - Daily simulation of system operations (time-step based)
      - Automatic assignment of missions based on priority and availability
      - Maintain multiple mission states dynamically
      - Console-based UI to display system status at each timestep
🔹 Technical Highlights
      - Implemented using Object-Oriented Programming (OOP)
      - Extensive use of:
            _Queues / Priority Queues
            _Linked Lists
      - Custom implementation of data structures (no STL / built-in shortcuts)
      - Modular design:
            _Request Classes
            _Mission Classes
            _MarsStation Class (core system controller)
            _UI Class for interaction and visualization
      - Efficient handling of dynamic data and state transitions
